Welcome to Local Gemma 4 V0.1.3. This version adds local file selection, a model-file checklist, and persistent diagnostics. The model runtime itself still needs to support loading every selected ONNX file from browser-managed file handles; this build tests that path and reports errors instead of silently closing the panel.
1. Download Gemma 4 E2B
Open the official repository. For this app, use the Q4F16 ONNX variant and download the required config, tokenizer/processor, decoder, and embedding files. Do not download every quantisation variant.
Open Gemma 4 E2B model repository ↗
Important: this repository contains many large files. Check each file's size and available iPhone storage before downloading.
2. Select your local files
On desktop, try the folder picker. On iPhone, use Select Files and select the downloaded files from Files. Some iOS browser versions do not offer folder selection.
